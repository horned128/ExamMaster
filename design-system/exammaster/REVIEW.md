# 追加レビュー：改善が明確な箇所だけ

## 対象・判断基準
SwiftUI / iPhone / iOS 17以上。既存の視覚言語を維持する磨き込み。
`taste-skill`のPreserve原則と、`impeccable`のOperate・polish・iOSガイドを適用。
Web向けのフォント変更・画像追加・ヒーロー構成・演出は適用しない。

## 残す
- 標準のTabView・NavigationStack・シート・SF Symbols・システムフォント。
- 学習量を自分で選ぶ導線と中断・再開。学習を強制しない短い案内。
- 実データの記憶バー、具体的な復習日、必要なときだけ開く説明。
- 学習・復習・記憶という目的の異なるグループ。カードを減らすこと自体は目的にしない。
- 問題リストの標準的な行・区切り。個々の問題をカード化しない。
- Dynamic Typeの縦配置、safeAreaInset、Reduce Motion、ライト／ダーク。

## 改善
| 課題 | 最小の修正 | 利用者への利益 |
|---|---|---|
| 学習件数が選択肢・大きな数字・開始ボタンに重複 | 単独の大きな数字だけ削除 | 開始操作を探しやすくし、スクロール量を減らす |
| 最大文字サイズで開始ラベルが3行になる | そのサイズだけ「始める」に短縮。件数は読み上げに保持 | 文字を小さくせず、ボタン全体を把握しやすくする |
| 年度別一覧の各行に同じ年度 | 年度で絞った一覧では科目のみ | 情報を失わず、一覧を読みやすくする |
| 全科目同点でも得意・伸びしろを命名 | 差がある場合だけ比較。出題しない科目は除外 | 根拠のない「分析された感」をなくす |
| 回答文字は拡大するがマーカーが28pt固定 | ScaledMetricでマーカーも拡大 | 大きい文字のはみ出しを避ける |
| 次月に進めない矢印が押せそうに見える | 無効状態を視覚的にも弱める | 操作可能な方向がわかる |
| 試験日ボタンの読み上げに残日数がない | accessibilityValueを追加 | 視覚に依存せず同じ情報を得る |
| 横向きの対応宣言がない | iOS標準のPortrait/左右Landscapeを明示 | 正しい回転と安全領域で操作できる |

## 検証の境界
Simulatorの画面とXCTestによる確認。実機の片手操作・VoiceOver実聴・長期の学習効果を検証したとはしない。
ネイティブのためWeb用Impeccable detectorは適用しない。

## 最終確認
- iPhone SE（375pt）/ iOS 26.2 Simulatorで、縦・横、ダークモード、最大文字サイズを確認。
- `EngineTests` 21件と、少なめの学習・横向き・最大文字サイズのUIテスト3件が成功。
- 既存のStoreKit購入／復元テストは一度終了直後の権限更新で不安定になったが、単独再実行で成功。決済コードは変更しない。
- 明暗のバッジ文字は4.5:1以上、両資格のダーク時リンクは7.5:1以上を確認。
- 大きな構成変更、追加アニメーション、Web由来のナビゲーション変更は行わない。
