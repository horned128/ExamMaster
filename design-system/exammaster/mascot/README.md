# 原案の相棒 — ひよこからチキンへ

**見た目の正本はユーザー作成のSVG。** [source/](source/) に原案をバイト単位で変更せず保存。重複した取り込み元と不採用の旧提案は整理しました。内部型名 `Tankei` はコードの連続性のために保持し、UIでは「相棒」と呼びます。

## 成長

利用可能な問題の **定着率と学習準備度** を内部で使用します。以下は開発仕様であり、成長の数値・計算説明・進捗バー・「あと何問」はアプリに表示しません。

```text
成長スコア = 定着率（0〜1）× 0.4 + 学習準備度（0〜100）÷ 100 × 0.6
```

| 内部スコア | 姿 | 原案の活用 |
| --- | --- | --- |
| 0〜0.25未満 | ひよこ | `hiyoko.svg` そのまま |
| 0.25〜0.60未満 | 育ちざかり | ひよこを足元から1.1倍、羽を1.18倍 |
| 0.60〜0.85未満 | 若鶏 | チキンを0.92倍、前腕を0.85倍、腹筋線を薄く |
| 0.85以上 | チキン | `niwatori.svg` そのまま |

中間段階は原案の変換だけで作り、輪郭を描き足しません。境界は `Core/TankeiIdentity.swift`、姿・角度は `tools/GenerateMascot.py` が正本です。

- 定着率は既存の条件（異なる3日以上の正解、安定期間7日以上、推定保持率0.75以上、誤解なし）。準備度は既存の `StudyStats` 計算を同じ利用可能範囲に適用し、範囲外の回答履歴は除外します。1回正解しただけでは定着とはみなしません。
- 無料版では無料問題が分母。課金・模試を必須にせず最後まで成長できます。購入済みは全問題が分母。記録画面の準備度は従来どおり問題集全体を評価し、成長用の内部値とは分けます。
- 最高段階を資格別の `study-<資格id>.json` に保存。誤答・時間経過・解放／問題追加で内部スコアが下がっても姿は戻りません。新しい数値も相棒UIには表示しません。
- **学習中は開始時の姿を固定。** 閾値に達しても、その演習が終わるまで変更・保存しません。中断・アプリ再起動・再開でも旧姿のまま。終了時に確定し、結果の前に専用の「成長したよ！」画面を表示。単問は解説を閉じる時、模試は終了・採点時に判定します。
- `mascotHighestStage` がない旧履歴も読み込み、同じ2指標から成長を補完。ただし途中演習があれば完了まで待ちます。既に保存済みの段階は新計算でも保持。スキーマは1のまま。破損履歴を上書きしません。
- 学習情報のリセットではひよこに戻ります。購入・広告同意とは独立。
- 定着率・準備度は成長の内部入力ですが、姿を合格率や合格判定と同一視しません。復習計算や模試判定は変更しません。

## アプリ全体の出番

「最小導入」から、ユーザー指定の **フル活用** へ拡張しました。

| 場所 | 役割と動き |
| --- | --- |
| 初回の診断案内 | ひよこが呼吸・まばたき。無料表示／開始／スキップを維持 |
| ホーム | 176ptの姿と吹き出し。学習状態に応じたセリフをタップで変更。資格名と定着／学習中／これからの3区分を表示し、ノルマ達成後はノルマのカードだけを隠す |
| 問題を探す | 176ptで首・羽・体を動かす。「どこから学ぼう？」から問題を選ぶ |
| 問題リスト | 重複した案内行を削除。検索結果なしでは相棒を含むネイティブ空状態 |
| 問題を読む間 | 右上の相棒は削除。模試中も表示しない |
| 回答後の解説 | 120pt。正解では2回のジャンプと羽ばたき／力こぶ、短い紙片。誤答では大きめのうなずき。反応後は呼吸と状態別の自動アクションへ戻る |
| 学習終了時の成長 | 256ptの専用「成長したよ！」画面。最大文字では192ptに調整。旧姿から新姿へクロスフェードし、結果へのボタンはすぐ使える |
| 連続演習・診断・模試の結果 | 成長後の姿で労い。重複した説明は削除。模試の合否は既存の判定を維持 |
| 記録 | 現在の姿とセリフの短い入口。全件回答への入口も相棒画面に統一。準備度・定着率は学習の状態に集約 |
| 記憶と復習ガイド | 復習の意味を説明する相棒。スクロールで画面外に出ると止まる |
| 設定 | 相棒画面への入口。資格ごとの姿を使用 |
| 学習の相棒 | 224ptの姿。「応援して」「力こぶ！」「ひと休み」で反応。日付ラベルの下にその日の全回答を並べ、新しい順（既定）／古い順を切替。履歴の問題を開いて閉じるとここへ戻る。リアクションと並替自体は学習データを変更しない |
| 決済／広告／同意／削除／エラー | キャラで判断を誘導せず、標準UIと正確な説明を維持 |

ベースサンプルは `ExamMaster` の1つ。同じ相棒でシリーズを統一し、資格識別はJSONの名前・UI色・チキンのベースカラーで行います。旧案の胸ワッペンや資格IDのハードコードは使いません。アイコンはチキンの顔＋資格名です。

`qualification.json` の `mascotBaseHex` で、チキンの頭・胴・肩・前腕・脚・しっぽを同じ色に差し替えます。未指定なら原案のクリーム色。`ContentView.swift` のEnvironmentからシート・成長画面・ガイドにも伝播し、成長計算・保存データは変更しません。ひよこ・トサカ・目・輪郭・くちばし・ほっぺは原案の色です。

アイコンの顔は同じ原案から生成した `chicken-face.json` を使用。`name` が既定の資格名、必要なら任意の `iconTitle` で短縮名／2行を指定できます。ビルド前の共通スクリプトがJSON変更時に透明部分のない1024px画像を自動再生成。手動では `swift tools/GenerateIcon.swift Qualifications/demo-safety/qualification.json Assets.xcassets/AppIcon.appiconset/AppIcon.png`、末尾の `--check` で設定との一致を検証できます。

## 部位と正本

### ひよこ

足 → 左右の羽 → 胴 → 産毛 → 顔。**羽が体の背面に隠れる原案の順序**を維持。頭と胴は一体なので、うなずきは足を残して胴を傾けます。

- 足元 `(128,210)`、胴 `(128,183)`
- 左羽 `(78,144)`／右羽 `(178,144)`、まばたき `(128,124)`

### チキン

しっぽ → 脚／足 → 胴 → 左肩／前腕 → 右肩／前腕 → 筋肉線 → 頭／顔。**肩を固定し、前腕の力こぶを動かす**構造を活用します。

- 足元 `(128,225)`、頭 `(128,122)`
- 左前腕 `(89,126)`／右前腕 `(167,126)`
- まばたき `(128,87)`、しっぽ `(180,164)`

原案の黄色 `#FFE259`、輪郭 `#243B3A`、トサカ `#F06D5E`、くちばし `#F2B544`、ほっぺ `#F7A38D` を保持。クリーム `#FFF3DA` は資格設定で差し替え可能（サンプルは原案色）。48pt未満はほっぺ・筋肉の細線を省略し、輪郭と顔は残します。イラストの色をUIの正誤トークンには使いません。

## 滑らかなモーション

`Canvas`＋`TimelineView(.animation)`＋iOS 17 `keyframeAnimator`。ランタイムSVGパーサー、WebView、Rive等のSDKなし。

### 待つ姿：`idle: true`

呼吸3.8秒、羽の揺れ4.2秒、しっぽ4.6秒、重心移動6秒を位相の違う滑らかな波で合成。約6.8秒ごとに0.22秒のまばたき。通常は最大1.8/256の上下、胴の変化0.7%、重心の傾き0.45°。ホーム・問題探し・相棒画面は `expressive: true` で振幅を3倍にし、動きが見えるようにしています。常時ジャンプや紙吹雪を繰り返しません。

加えて **20種類のアクションプリセット** を状態と姿に合わせてランダム選択。同じ動きは連続させません。羽ばたき、力こぶ、小ジャンプ、見回し、うなずき、背伸び、うたた寝、手振り、2段ジャンプ、ゆらゆら、おじぎ、のぞき込み、くねくね、胸を張る、眠いまばたき、つま先立ち、首振り、肩すくめ、ダンス、しっぽ振り。ひよこは力こぶを選ばず、復習・再挑戦・休憩ではジャンプ／ダンスを選びません。

1回2.8秒、4.2〜6.8秒間隔。滑らかな包絡線で呼吸へ戻り、手動反応の最初の1.5秒は自動アクションを抑制。表示外・非active・Reduce Motion・省電力・覆われた画面では選択タスクもキャンセルし、不要な更新を止めます。

### 反応：`animated: true`

少しふんばる → 羽ばたく／力こぶを上げる → うなずき・まばたき → 戻る、約1.4秒の有限再生。強調時は振幅2.4倍。正解は2回のジャンプ＋12片の局所的な紙片、誤答はうなずき＋4個の小さなアクセント。springとcubic keyframeでつなぎ、待つ姿へ自然に重ねます。ホーム・相棒画面・解説・結果では呼吸と自動アクションへ戻ります。操作や画面遷移を待たせません。

6状態：`ready`、`encourage`、`celebrate`、`review`、`recover`、`rest`。原案の笑顔は維持し、誤答で怒る・泣く・倒れる・罪悪感を誘う表現はしません。模試の全体＋科目基準を満たさない結果は、成長しても合格の祝福へ置き換えません。

### 成長

学習終了時にだけ判定し、専用画面で約0.4秒のクロスフェード。構造の違う2原案を無理にパスモーフせず、旧姿 → 新姿の連続性を保ちます。「成長したよ！」と段階名をネイティブ文字でも表示。

### 描画予算・アクセシビリティ

- 毎フレーム作り直すのは変換と軽い三角関数。**パス・色・線設定は初回に生成してキャッシュ。** SVGは実行時に読み込みません。
- 表示中の相棒だけ最大60Hzの更新を要求。スクロールで画面外、タブ離脱、裏に隠れた画面、非active、Reduce Motion、省電力ではタイムラインを破棄して静止描画。
- 見た目は固定フレーム内で動き、UIのレイアウト・ボタンは動かしません。
- 装飾はVoiceOverから除外。ホームの相棒ボタン、成長段階、日付見出し、回答の正誤・問題文・時刻、結果はネイティブのラベルで提供。成長の数値は読み上げにも含めません。
- Dynamic Typeのアクセシビリティサイズでは縦配置。相棒のリアクション操作も横に収まらなければ縦配置。
- **実機60fpsの保証ではありません。** 端末の表示周期に従い、iOS 17実機／Instrumentsで検証が必要です。

## 生成・動作確認

```sh
# 別の原案を取り込む場合のみ。入力ファイルは変更しない。
python3 tools/GenerateMascot.py --import-source path/to/originals
python3 tools/GenerateMascot.py
python3 tools/GenerateMascot.py --check
```

出力：`TankeiArtwork.swift`、`growth-poses/` の4段階×6状態、各2種のcompact／silhouette、`rig.json`、アイコン用 `chicken-face.json`。M/L/C/Q/Zとcircle、継承fill／strokeをコンパイル。対応しない構文は生成時に停止。手編集はsource側で行い、Swiftの生成物は直接編集しません。

```swift
TankeiView(state: .ready, stage: growth.stage, size: 96, animated: true, idle: true)
```

通常アプリではホームの相棒をタップ。開発時はXcode Preview「原案の相棒・成長と動き」、または以下のギャラリーで内部スコア0／25／60／85と6状態を比較できます。Debugギャラリーの値は表示検証だけの入力で、実際の学習スコアを表示せず履歴にも触れません。Releaseには入口を含めません。

```sh
xcrun simctl launch booted jp.example.exammaster.demo -TankeiGallery
```

Riveは未導入。必要なら2つのsource SVGを別artboardに取り込み、`rig.json` の基点を使用。`.riv` なしにSDKや動かないサンプルを追加しません。
