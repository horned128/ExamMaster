# 2026年予想問題 第1回

2026-10-11。新規オリジナル25問・40分。IPAの2026年公式問題ではなく，出題的中を保証するものでもない。アプリ内のカード，問題のkindと出典，固定模試名で「予想」「ExamMaster オリジナル」を表示する。有料の既存買い切り権限に含め，未購入で問題文・解説へ入れない。

まず第1回25問を制作した後，同日の利用者依頼で第2・3回を各25問追加し，全3回75問となった。第1回の本文・ID・レビュー固定ハッシュは保持。難易度は基本5・応用15・発展5，分野はネットワーク16・セキュリティ5・コンピュータシステム2・システム開発技術2。

## 二つの確認観点

1. 作問後に，本文の仮定，四肢の相互排他性，正答，四肢の理由，解説と手順，過去問と区別したID/出典を25問それぞれ確認。数値・ネットワーク構成・条件は独自に設定し，公式問題からの原文転記として扱わない。
2. 別の確認観点でRFC本文を参照し，リンク層解決と名前解決，暗号化と完全性，AS経路とIP経路，長期署名鍵と一時鍵，0-RTTの再生とアプリケーション再試行を比較。計算を本文の説明から離して標準ライブラリ・有理数・全状態列挙で検算した。Pythonの9件は自動レビュー承認ではなく，この照合を補助する回帰検査。

**制作内AIレビュー。別人の専門家による独立校閲を実施したとは称さない。**
