## 確定した表示範囲と証拠

- finalの各`-evidence/manifest.json`は成功3テストの検査版/測定値/実画像23点のSHA-256を保持。既存の証拠を上書きしない。
- 本文表（2024問3），選択肢表（2024問12/2025問15）の見出し/値と横移動，等幅選択肢（2024問11ウ），独自ビット例，通常演習/成績詳細の呼量式，成績詳細のTCP手順の空白/改行/横移動/縦末尾への到達を確認。全原式が最大文字で同時に一画面に収まるという意味ではない。
- 原順の正答イ/ウ/エと，2025模試の問15だけ正答・未回答24問，未回答の問1/11の解説開閉，結果からライブラリへ終了する操作に成功。
- finalの採点結果/終了ボタン（`020.png`），独自図説明（`027.png`），表の左右/式/末尾の代表画像を両配色で目視。表の全行や全教材の全スクロール位置を画像だけで網羅したとは称さない。
