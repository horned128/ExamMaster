- 問6のZ-X/Y-A/B/C/Dと全6接続を4倍の891×445 PNGで目視。Aの次ホップのMACとCのMACを解決するルータを分け，L2スイッチのMAC-port学習と混同しない。プロキシARPなしを保持。
- 問10：FFFFFF80→255.255.255.128→/25，ホスト総数128から予約2個を除く126を標準IPv4計算でも独立検算成功。
- 問14：URLのhostのftpとqueryのport=123は接続プロトコル/ポート指定ではない。HTTPS既定443を`urlsplit`でも検算成功。例示URLへ実アクセスはしない。

- 問9：RFC4511 §5.2のTCP，RFC4512 §5.1のserver自身のroot DSEを直接確認。世界共通のLDAP rootサーバとは説明しない。
