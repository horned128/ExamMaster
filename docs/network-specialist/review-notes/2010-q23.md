## 解説の技術レビュー

各通信路の故障が独立という通常の信頼性計算モデルで，通信路の稼働率をp＝1−Fとする。

- R_A＝1−(1−p²)²：稼働率p²の二つの直列経路を並列化。
- R_C＝(1−F²)²：2通信路を並列化した区間を二つ直列接続。
- R_B＝p R_C＋F R_A：中央通信路が稼働すると左右それぞれの並列区間が使え，故障するとA案と同じ。
- R_C−R_A＝2p²F²＞0。
- R_B−R_A＝p(R_C−R_A)＞0，R_C−R_B＝F(R_C−R_A)＞0。

したがって公式正答エのC案＞B案＞A案となる。原文で独立性は明示されていないため，解説では計算モデルの仮定を明示し，独立でない任意の故障まで同じ式が成立すると断言しない。

2026-10-09の別方法の検算：A/Cの各16状態，Bの32状態について，稼働する辺だけを使ったグラフ到達可能性で成功状態を列挙した。F＝1/20〜19/20の19点で，各状態の確率をPython `Fraction`で厳密に加算し，上記3式・差の式・C＞B＞Aに一致した。さらに状態確率を二項展開して，R_A＝2p²−p⁴，R_B＝2p²＋2p³−5p⁴＋2p⁵，R_C＝4p²−4p³＋p⁴という整数係数多項式に一致することを確認。三つの差も厳密一致し，全区間での正値因数分解と整合する。`tools/network-specialist/test_reviewed_calculations.py`の回帰2件として保存，成功した。
