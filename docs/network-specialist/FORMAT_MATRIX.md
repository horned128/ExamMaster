## 検証原則

- 白背景の原図をダークモードで反転しない。表示のための図表分割と，内容の改変を区別する。
- 校合ハッシュにはPNGのバイト列も含める。同名差替えでも再レビューが必要。
- 表は見出しとセルの対応を保持し，横スクロールで読めることと読み上げ可能な列ラベルを確認する。
- 解説の図・式・例は独自作成である旨を明記し，公式原図と混同しない。
- 模試の下部操作は`ViewThatFits`で最大文字時に縦配置。74問版ダークで最大文字UI成功，残り時間の全桁と下部操作を添付画像でも確認。小画面の結果も`STATUS.md`に記録する。
- 横長の短い選択肢画像も図版ボタンのタップ高さを44pt以上にする。拡大は回答選択と別操作で，未回答のまま図を確認できることをテストする。
- ダーク時も図拡大内容/ツールバーだけライト配色とし，原図の白地を保持したままタイトル・閉じる・拡大/縮小/全体表示を読めるようにする。閉鎖後に元の演習/模試配色を変えないことを，拡大前後の実画像と画面ピクセル検査で確認する。
- 無効な通常演習の確定ボタンも操作名が読め，回答選択前に有効化されないことを確認する。AXフッターの矩形はsafe areaを含むため中心一点で文字を検査しない。中央帯の局所コントラスト検査と実画像を併用し，測定器の合成画像回帰を実教材表示の成功件数とは区別する。
- 模試の有効な「終了して採点」「学習を終える」もリンク色と塗りボタン色を混同しない。既存の`Palette.accent`/`Palette.onAccent`で局所修正し，両配色の最大文字で約5.86:1の実ピクセル検査（しきい値4.5）と結果から終了する操作に成功。全画面のコントラスト/VoiceOver適合は別工程。
