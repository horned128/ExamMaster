# App Store screenshot storyboard

Target: iPhone portrait, 1320 × 2868 px, Japanese. The six screens follow a path from learning approach to topic selection, practice, feedback, and price.

| Order | Headline | Supporting copy | Actual app screen | Verified point |
|---|---|---|---|---|
| 01 | 答えを思い出す練習を。 | 想起練習と、間隔をあけた復習の考え方。 | Learning guide introduction | Research-informed retrieval and spacing approaches are described, alongside an explicit note that this app's own learning effect/pass-rate lift has not been experimentally established. |
| 02 | 学びたい分野を、マップで。 | テーマごとの問題数を見て、タップで選択。 | Technology subject topic map | Six thematic nodes are linked to the subject center; each node displays question and learned counts and navigates to that topic. |
| 03 | テーマを選んで、さらに絞る。 | 問題数と学習状況を見て、次の課題へ。 | Security subcategory list | The selected topic leads to a second level with counts, free/paid scope, and progress. |
| 04 | 問題も、テキストで読みやすく。 | 図が必要な問題だけ、画像で表示。 | Native text question | The question and four answers are selectable text; the UI uses a figure only where needed elsewhere. |
| 05 | 選択肢ごとの根拠まで。 | 正解だけでなく、ほかの選択肢も確認。 | Detailed explanation | The correct answer has its reasoning and each distractor has an individual explanation. |

## Evidence behind the learning wording

The app's guide cites studies on retrieval practice and distributed practice. The listing wording describes those learning approaches and the app's implementation; it does not promise that this app itself improves exam outcomes. The app guide explicitly says its own effect and any pass-rate increase have not been proven by a comparative experiment.

- Dunlosky et al. (2013), review of learning techniques: practice testing and distributed practice are evaluated as useful techniques. [APS / journal page](https://doi.org/10.1177/1529100612453266)
- Roediger & Karpicke (2006), delayed retention after retrieval practice versus restudy. [PubMed](https://pubmed.ncbi.nlm.nih.gov/16507066/)
- Cepeda et al. (2006), meta-analysis of distributed practice and retention interval. [PubMed](https://pubmed.ncbi.nlm.nih.gov/16719566/)

The source app captures remain separate image assets. Poster design adds only editable text, background, and framing around each image; it does not retouch, repaint, or place copy over the app UI.
