# 公開過去問の収録・表示確認

確認日：2026-10-15。2023〜2026年度のIPA公開問題104問（各年科目A20問・科目B6問）を収録。正答は公開解答例の記号に固定し、全104問を照合済み。原本16PDFのURLとSHA-256は `sources.json` に保存した。

## 収録形式

問題文をテキスト・コード・表・図に分け、スマートフォンで読める順に再構成した。逐語の電子復刻ではなく、一部の長文は段落の整理や条件表への再構成を行っている。図を関係表に置き換えたものもある（2024年度科目B問3の無向グラフは辺一覧と隣接行列）。選択肢、解答に必要な条件、空欄の位置を保持する方針。

科目Aの8図版は原本から切り出し、ページ・座標を `figure-crops.json` に記録。拡大表示に対応する。文字抽出時にページをまたいだコード、抜けた空欄a/b/c、代入式、関数見出しを生成スクリプトで補修した。2024年度科目B問5は関連度の式・定義・配列のゼロ初期化を明示し、全商品の購入回数と共起数を別実装で検算した。

## 検証

- `validate.py`：全104問の公式キー、全16原本のハッシュ、図版、表の列数、選択肢数と空欄の基本構造を確認。
- `verify_official_calculations.py`：23問の計算・論理・コード・図表結果を別実装や直接計算で確認。全8ビット値の2進数変換と、併合処理、商品関連度も含む。
- `past.py`：全年度を繰り返し生成しても104問を維持。年度指定時は当該年度だけを置換する。
- 科目Bの表示はコードの画面幅折り返し、字下げ、行番号、文字サイズ選択、読解画面内の移動で確認する。

解説の修正履歴と制作内別担当の検算範囲は `review-independent.md` を参照。解説はアプリ独自の説明で、IPA公式解説ではない。外部専門家の全問校閲は未実施であり、自動検査の通過だけで全記述の事実監査を保証しない。
