# 科目Bオリジナル問題 第1〜12回 制作・検算メモ

## 収録構成

- 12セット、各20問、計240問。各セットはアルゴリズム・プログラミング16問と情報セキュリティ4問で、試験時間は各100分。
- アルゴリズムは20ファミリーを採用し、各ファミリーを「実行結果」「指定段階の状態追跡」「境界・停止条件」「計算量・不変条件」の4角度から出題する。ファミリー×角度で80の設問設計を含み、入力を変えた演習を合わせて192問を収録。
- 20ファミリーは区間集計、括弧列、ラウンドロビン、挿入法、下限二分探索、再帰、互除法、対角集計、連続長圧縮、幅優先探索、基数変換、線形探索ハッシュ、連結リスト、固定幅窓、転倒数、硬貨DP、整列済み列の併合、回文判定、選択法、逆ポーランド記法。
- セキュリティは12テーマに各4件の個別事例を置いた計48問。本文の状況、最適対応、正答文は48件で重複しないことを生成時に検査する。
- 正解を含む計算トレースは `explanationBlocks` に置き、解答前に見える `bodyBlocks` には前提・入力・コード・設問だけを含める。本文の最後は一覧用のstemと一致させている。

## 検算

`python3 tools/fundamental-information/practice_b.py --verify` はJSONを生成し、240件・12セット、ID、選択肢と解説の件数、一意性、セットごとの科目構成、解説側トレースとの回答一致、本文末尾、bodyBlocksに表が含まれないことを検査する。実行結果角度の回答は、生成用の `compute` と分けた `reference_result` で各入力を再計算する。境界角度の回答は具体的な誤条件・誤実装、計算量角度の回答はファミリーごとに定義した変数で照合する。

境界選択肢は各ファミリーで3つずつ具体的に作り、添字ずれ、比較条件、停止条件、未処理要素、ループ範囲等を示す。計算量選択肢は問題文内に定義した同じ変数記号を使う。行列・ハッシュ表・窓処理など固定サイズの例を一般化して見積もる場合は、その一般化条件を設問中に明記する。

擬似コードで用いる配列要素番号は1始まりとし、必要な初期値、範囲、停止条件を本文に記載する。グラフは有向グラフまたは隣接リストとして明示する。配列参照は先に範囲条件を成立させてから行う。窓の最大値とDP配列は初期化し、挿入法・選択法の計数変数も0で初期化する。
