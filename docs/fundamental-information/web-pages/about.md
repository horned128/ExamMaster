# ピヨトレ！基本情報技術者

基本情報技術者試験の科目A・科目Bを、学習の相棒と一緒に練習できるアプリです。

【合計1,004問】
2023〜2026年度のIPA公開問題104問と、現行シラバスVer.9.2を参考に作成したオリジナル練習問題900問を収録。年度別・分野別、苦手問題、ブックマーク、Lv別小テストで取り組めます。同じ学習目標を異なる形式や入力で復習する問題を含みます。

【科目Bの長文を読みやすく】
問題文・コード・表・設問を区切って表示。コードは画面幅で折り返し、元の行番号と字下げを保ちます。文字サイズを調整でき、本文を別表示しながら回答を保持できます。

【科目ごとの模試】
オリジナル模試は科目A60問・90分、科目B20問・100分。公開過去問は各年科目A20問・科目B6問の抜粋で、短時間演習として収録しています。

【まずは184問を無料で】
公開過去問104問と第1回のオリジナル科目A60問・科目B20問は無料。300円の買い切り購入で全問題を解放し、広告を停止します。定期購入はありません。購入の復元にも対応します。

アカウント登録は不要。学習履歴は端末内に保存します。無料版にはバナー広告と、一定の学習回数・時間を空けた学習の区切りで全画面広告を表示する場合があります。

本試験のIRT評価点とアプリの正答率は異なります。アプリの正答率60%は練習の目安で、合格を保証するものではありません。

公開過去問題と解答例の著作権はIPAに帰属します。本文の段落・改行・図表をスマートフォン向けに再構成しています。解説とオリジナル問題は本アプリ独自のもので、IPAが作成・監修したアプリではありません。
