# ピヨトレ！基本情報技術者 サポート

科目Aと科目Bの学習に対応したiPhone用アプリです。iOS 17.0以降に対応します。

## 教材と購入

収録数は1,004問（IPA公開問題104問、オリジナル900問）。無料範囲は184問です。全問題解放は300円の買い切りで、購入後は広告を停止します。定期購入はありません。公開過去問は各年度の抜粋で、本試験全問を収録したものではありません。

## 購入の復元

購入時と同じApple Accountでサインインし、アプリ内の設定から「購入を復元」を実行してください。学習情報のリセットと購入権限は別に扱います。

## 科目Bのコード・長文

コードの「表示設定」から文字サイズと折り返しを選べます。「本文を別表示」で読解画面を開き、「本文内を移動」でコードや図表へ進めます。読解画面を閉じても選択中の回答は保持されます。

## 学習履歴の削除

「設定」→「データとプライバシー」→「学習情報をリセット」から回答・習熟度・模試等を削除できます。購入権限・広告同意・表示設定は維持されます。

## 教材の訂正・お問い合わせ

不具合や教材の訂正は hino_lizard581@icloud.com へご連絡ください。問題IDまたは年度・科目・問番号、アプリのバージョン、端末とOS、再現手順を記載してください。パスワードや決済カード情報は送らないでください。

過去問題の著作権はIPAに帰属します。解説・オリジナル問題は本アプリ独自のもので、IPAによる作成・監修ではありません。
