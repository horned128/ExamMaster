# 過去問解説の制作内別担当による再計算・校閲

確認日: 2026-10-15  
対象: `content/past.json` の2023〜2026年度公開問題 104問（各年 科目A 20問、科目B 6問）

## 照合方法

- 104問すべてについて、`sources.json` に収録したIPA公開解答キーの正答記号と、`past.json` の `correctIndex` が指す選択肢を機械照合した。全問一致。
- 計算・コード問題18問と、図表・論理問題2問を独立に再計算・トレースした。実行コマンドは `python3 tools/fundamental-information/verify_official_calculations.py`。可用性、会員継続率、再帰式（n=1〜12）、回線利用率、クリティカルパス、損益計算、倍数列挙、硬貨組合せ、文字列探索、独立時の期待度数、キャッシュヒット率、16進小数、クイックソートの初回分割、ハッシュ配置、真理値表、および散布図の相関方向を照合している。
- 原本はIPA公開問題のローカル保存版（`originals/2023r05`〜`2026r08`）と図版を参照した。2025年度科目B問4は冊子PDFの当該ページを直接開き、配列 `{a,b,a,b,c,a,b,c}` とキー `{a,b,c}`、不一致時の内側ループ終了処理を確認した。
- `explanation`、`steps`、`choiceExplanations` は上記の計算・コード問題について選択肢と逐次トレースに照らして校閲した。さらに2024年度科目A問1の真理値表を原本から再構成し、問19の散布図を図版で確認した。残る知識問題については公式キーとの正答一致と内容の整合性を確認したが、全誤答選択肢の個別記述について専門家による網羅的な事実監査を保証するものではない。

## 適用限界

本レビューは、制作チーム内の別担当による104問のキー照合と、明記した20問の独立計算・論理確認・トレースに基づく。外部の独立専門家による監査ではなく、全選択肢を原本から一字一句検証したことを意味しない。図表の読取りや制度・用語解釈で疑義があったものは断定せず、修正が必要な項目として担当に共有する。各年の公開キーはIPA公開問題ページから取得した内容を `sources.json` に記録している。

参照: [IPA 基本情報技術者試験 公開問題・解答例](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/index.html)
