# 2027年実施向けオリジナル予想 第1〜3回

2026-10-17制作。ネットワークスペシャリスト・応用情報版の「オリジナル3回の固定セット」にならい、電験三種は**各回を4科目に分けて**収録します。公式問題を追加したものでも、実際の次回出題を知っているという意味でもありません。

3回合計198大問・240解答欄・12科目セット。理論と機械の問17／問18は一方の(a)(b)を選択し、通常演習では両方を練習できます。法規はA問題各6点、問11・12の(a)6点／(b)7点、問13の(a)(b)各7点です。採点は正答数と得点を分けます。全320解答欄（公式80＋予想240）が無料です。

## 出題範囲と制作

- 理論：静電気・磁気、直流／交流・三相回路、過渡現象、半導体・増幅回路、電気計測。B問題は電源と負荷、並列交流回路、電磁誘導、電子回路の条件付き計算。
- 電力：水力・火力・原子力・再生可能エネルギー、蓄電、変電設備、保護、架空／地中線路、接地方式、配電、電気材料と需給。B問題は発電出力・電力量、張力・たるみ、配電の電圧降下・抵抗損。
- 機械：直流機・誘導機・同期機・変圧器、電力変換、電動機応用、照明、電熱、電気化学、制御と情報処理。B問題は誘導機の電力流、変圧器の損失・効率、電熱、論理式。
- 法規：小規模事業用電気工作物、電圧区分、接地・絶縁、地中線路、系統連系、サイバーセキュリティ、風車、主任技術者と保安管理。B問題は需要率・負荷率、変圧器損失・電力量、力率改善と線路損。

A問題は各回で問う原理・条件を変えています。B問題には、同じ分野の習熟度を比較できるよう、共通する計算形式の条件違いも含めます。正答の位置は科目内で均等にしたうえで固定乱数で混ぜ、単純な循環順にはしません。選択肢だけの再配列による重複問題は作りません。本文240件はすべて異なります。

本文・数式・選択肢・解説はアプリ独自のテキストです。回路を図で示さない場合は直列／並列、接続先、内部抵抗、相／線間値、効率・損失等の前提を文章で明示します。(b)の画面にも共通条件を含め、(a)に正解しないと読めない構成を避けています。

法規は2026年10月17日に確認できる公式公開資料を基準とし、将来の本試験に適用される法令の基準日を推定していません。具体的な適用日や変更は公式受験案内に従います。

## 再生成と検証

```sh
python3 tools/denken3/assemble_bank.py --skip-render
python3 tools/denken3/validate.py
python3 tools/denken3/verify_predictions.py
```

`prediction_theory.py` / `prediction_power.py` / `prediction_machine.py` / `prediction_law.py` が問題・解説の編集元、`predictions.py` がセット・表示・配点を生成します。

`verify_predictions.py` は編集元の正答を参照せず、別に計算・記録した未丸めの正答で数値問題146解答欄の最近接選択肢が一意であることを照合します。論理式は全入力で等価性を確認します。6グループの自動検証は通過済みです。教材検証では公式80解答欄の正答を維持し、予想240解答欄の重複・形式・出典表示と全16科目セットの両選択経路100点を確認します。

制作内AIでの作成・検証であり、試験センターの作成・監修や、外部専門家による独立した校閲ではありません。

2026-10-17、iPhone 17 Pro / iOS 26.2の専用シミュレータで単体6件＋UI5件の全11件が通過しました。予想3回の科目別入口、テキスト問題の正答・解説、第3回法規の65分・16解答欄まで操作確認済みです。結果は `/private/tmp/DenkenThirdPredictionsVerified.xcresult`、教材のハッシュと検証件数は `prediction-verification.json` に保存します。
