# ピヨトレ！ネットワークスペシャリスト

**かわいい相棒と、ネットワークの理解を一歩ずつ。**

ネットワークスペシャリストの科目A-2（旧午前Ⅱ）を学ぶiPhoneアプリです。学習状況をひと目で確認し、年度別・分野別から目的の問題へ進めます。

## 375問で、基礎から本番練習まで

| 教材 | 収録内容 |
| --- | --- |
| 過去問 | 2013〜2025年の12回・300問（2020年は対象試験なし） |
| 2026年予想問題 | ピヨトレ！オリジナル3セット・75問 |
| 無料で学習 | 2023〜2025年の全75問 |
| 模擬試験 | 各25問・40分 |

## 迷わず選べる学習メニュー

- 年度別の過去問演習と、関連テーマから選べる分野マップ
- 正答・解説・選択肢ごとの理由・解き方
- 各25問・40分のオリジナル2026年予想模試3セット
- 苦手問題、ブックマーク、Lv別の小テスト
- 学習記録、相棒の成長、任意の試験日と残り日数

## 無料で始めて、買い切りで全問題を解放

アプリ本体と直近3年の75問は無料です。**480円の買い切り購入**で全375問を利用でき、広告も停止します。定期購入はありません。

アカウント登録は不要です。学習記録は端末内に保存します。かわいい相棒が、学習の積み重ねとともに成長します。

現在、App Storeでの公開準備を進めています。提供開始後にダウンロード先をご案内します。

## 過去問の正答について

当時のIPA公式正答に沿って採点します。出題内容と仕様の解釈に注意が必要な問題には、回答後の解説に補足を載せています。

過去問題の著作権はIPAに帰属します。解説と予想問題は本アプリ独自のものです。IPAが作成・監修したアプリではありません。予想問題は公式の2026年問題ではありません。
