# 使い方・よくある質問

## 学習を始めるには

ホームの「年度別」「分野別」から問題を選べます。年度別は分野ごとの問題一覧と模擬試験、分野別は関連テーマのマップから問題一覧へ進みます。購入が必要な教材は入口に鍵を表示します。

## 回答後はどうすればよいですか

答え合わせと解説を読んだら「次の問題へ」で進みます。最後の問題では「問題一覧へ戻る」を使います。「自信なし」「迷った」「自信あり」は回答後にも変更できます。解き方は答え合わせ後にまとめて表示します。

## 途中から再開できますか

途中再開はありません。問題一覧へ戻る・中断する・アプリを開き直すと、途中の位置を破棄します。通常演習の回答済み記録は残ります。模擬試験は採点時に記録し、採点前に中断した選択は保存しません。

## 購入した教材を使えません

購入したときと同じApple AccountでApp Storeにサインインし、通信できる状態でアプリの「設定」または購入画面から「購入を復元」をお試しください。買い切り購入は有料教材の解放と広告停止を含みます。返金等で購入権限がなくなった場合は、無料範囲へ戻ります。

## 何問を無料で使えますか

2023〜2025年の全75問を無料で学習できます。300円の買い切り購入で、過去問300問と2026年オリジナル予想問題75問の計375問を利用でき、広告が停止します。予想問題は3セット、各25問・40分の模擬試験としても練習できます。

## 古い問題の正答が現在の仕様と違うように見えます

過去問は当時のIPA公式正答を採点基準としています。2015年問9・2018年問17・2024年問22など、仕様や表現の解釈に注意が必要な問題には、回答後に公式正答と仕様上の補足を表示します。

## オフラインでも学習できますか

同梱された利用可能な教材はオフラインで学習できます。商品の取得・購入・購入復元・広告・外部リンクには通信が必要です。

## 試験日を変更したい

ホームの試験日欄の編集ボタン、または「設定」の「試験日」から変更できます。保存後はホームに今日の日付、試験日、残り日数を表示します。試験日の設定は任意です。

## 学習記録を削除したい

「設定」→「データとプライバシー」→「学習情報をリセット」を使います。回答履歴・習熟度・模試成績・ブックマーク・相棒の成長等を削除します。買い切りの購入権限は削除されません。操作を確定する前にアプリ内の確認文をご覧ください。

アプリ独自のアカウント・クラウド同期・別端末への履歴移行機能はありません。アプリを削除すると端末内の学習記録を失うことがあります。iOSのバックアップ・復元はAppleの設定や状態に依存します。

## 広告のプライバシー設定を変更したい

同意の変更が必要な場合は「設定」→「データとプライバシー」に変更ボタンを表示します。トラッキングの許可はiOSの「設定」→「プライバシーとセキュリティ」→「トラッキング」でも変更できます。許可しなくても無料問題を学習できます。

## 問題の誤り・不具合を報告したい

下記のサポート用メールへ、年度・回・問題番号または分野、気になった箇所、端末名、iOSとアプリのバージョンをお知らせください。再現手順や必要なスクリーンショットがあると確認に役立ちます。パスワード・決済カード情報は送らないでください。
