かわいい学習の相棒と、過去問・予想模試をこつこつ。

ネットワークスペシャリストの科目A-2（旧午前Ⅱ）を学ぶiPhoneアプリです。現在は公開準備中です。提供開始後にダウンロード先をご案内します。

【主な機能】
年度別・分野別の演習、正答と全選択肢の解説、苦手問題、ブックマーク、Lv別小テスト、学習記録に対応。オリジナル2026年予想模試は3セット、各25問・40分です。収録範囲と問題数は公開時のアプリ・ストア説明をご確認ください。

アカウント登録は不要。学習記録は端末内に保存します。無料範囲は購入せずに学習でき、有料教材と広告停止はアプリ内の買い切り購入で利用できます。定期購入はありません。

【購入した教材を使えない場合】
購入時と同じApple AccountでApp Storeにサインインし、通信できる状態で「設定」または購入画面の「購入を復元」をお試しください。

【回答と中断】
答え合わせ後は「次の問題へ」、最後は「問題一覧へ戻る」で進めます。回答後も自信度を変更できます。途中再開はありません。通常演習の回答済み記録は残りますが、模試を採点前に中断した選択は破棄します。

【試験日と学習記録】
ホームの試験日欄または「設定」から試験日を保存すると、今日・試験日・残り日数を表示します。記録の削除は「設定」→「データとプライバシー」→「学習情報をリセット」から行います。購入権限は削除されません。

【オフラインと広告】
利用可能な同梱教材はオフラインで学習できます。購入・購入復元・広告には通信が必要です。必要な場合は「データとプライバシー」から広告のプライバシー設定を変更できます。トラッキングを許可しなくても無料問題を利用できます。

【問題の誤り・不具合の報告】
下記メールへ年度・回・問題番号、端末名、iOSとアプリのバージョン、気になった箇所や再現手順をお知らせください。パスワード・決済カード情報は送らないでください。

過去問題の著作権はIPAに帰属します。解説と予想問題は独自のもので、IPAの作成・監修ではありません。予想問題は公式2026年問題ではありません。
